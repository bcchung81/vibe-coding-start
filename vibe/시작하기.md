# 내 웹앱 시작 폴더 (vibe)

이 폴더 하나가 내 웹앱 저장소다. 규칙(`AGENTS.md`), 명령 3개(`vibe-plan` · `vibe-develop` · `vibe-design`), 주제 카드(`topics\`), API 시험 스크립트, Next.js 뼈대가 들어 있다. 사전설치(`setup.ps1`)가 `C:\workspace\vibe` 에 만들어 둔다.

## 1. 폴더 열기 (1일차 1교시)

PowerShell에서 이 폴더로 가서 Codex를 연다.

```powershell
cd C:\workspace\vibe; codex
```

## 2. 교시별로 부르는 명령

`02` 자리에 내 주제 번호를 넣는다. 번호는 `topics\` 파일 앞 두 자리이고, 교육 허브 "웹앱 주제" 화면 번호와 같다.

| 언제 | 시킬 말 |
|---|---|
| 1교시 — 조사: 주제 카드의 API 상세 페이지 → `api-notes.md` | `ego-browser 스킬로 topics 폴더의 02 카드에 있는 API 상세 페이지를 열어서 요청 주소, 요청 변수(필수 여부), 응답 항목을 api-notes.md 표로 저장해줘. 로그인 화면은 열지 마` |
| 1교시 — API 시험: 아래 3번으로 키를 넣은 뒤, 5건만 불러 → `api-test.md` | `vibe-plan 스킬로 주제 02 API 시험해줘` |
| 2교시 — 처음 준비 (`git init` · 패키지 설치 · 빌드 확인) | `시작하기.md 대로 준비해줘` |
| 2교시 — 화면 구성 기획: AI 질문에 답 → `PRD.md` → `PLAN.md` | `vibe-plan 스킬로 화면 구성 기획해줘` |
| 3교시 — 한 단계씩 만들기 (새 창에서 `npm.cmd run dev` 를 켜 두고, 단계마다 반복) | `vibe-develop 스킬로 다음 단계 해줘` |
| 3교시 — 디자인 (impeccable 스킬을 쓴다) | `vibe-design 스킬로 화면 다듬어줘` |
| 3교시 — 전부 점검 · 커밋 | `vibe-develop 스킬로 PLAN.md 완료 기준을 ego-browser로 전부 점검해줘` → `커밋해줘` |
| 막혔을 때 | `vibe-develop 스킬로 이 오류 고쳐줘` 다음 줄에 오류 원문 |
| 4교시 — 공개 | 아래 3번으로 Vercel 토큰을 넣은 뒤 `vibe-develop 스킬로 배포 전 점검해줘` → `vibe-develop 스킬로 배포해줘` (이름 예: `kca02-hong`) — 프로젝트 만들기 · 키 등록 · 배포는 AI가 토큰으로 한다 |

## 3. 키 · 토큰 넣기 (본인이 직접)

에이전트에게 키 · 토큰 값을 말하지 않는다. 처음 한 번 PowerShell에서:

```powershell
Copy-Item .env.example .env.local
notepad .env.local
```

| 줄 | 언제 | 넣는 값 |
|---|---|---|
| `DATA_GO_KR_KEY=` | 1교시 API 시험 전 | 공공데이터포털 마이페이지의 **Decoding** 키 |
| `VERCEL_TOKEN=` | 4교시 배포 전 | vercel.com 에 GitHub로 가입 · 로그인 → 오른쪽 위 프로필 → **Account Settings → Tokens** → 이름 `kca-교육` · 만료 **1일** → Create → 한 번만 보이는 토큰을 바로 복사 |

- Vercel CLI는 사전설치가 넣었다. 새 창에서 `vercel.cmd --version` 으로 확인하고, 없으면 `npm.cmd install -g vercel`.
- 토큰은 내 Vercel 계정 전체 권한이다. 교육이 끝나면 같은 Tokens 화면에서 지운다.

## 4. 명령을 다른 폴더에서도 쓰려면 (전역 설치)

```
이 프로젝트의 vibe 명령을 전역에도 설치해줘
```

에이전트가 `AGENTS.md` 의 "전역 설치" 절차대로 내 PC의 전역 스킬 폴더에 복사한다. 설치가 끝나면 Codex를 다시 연다.
